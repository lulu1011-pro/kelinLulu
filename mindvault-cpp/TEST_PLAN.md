# MindVault 功能检测方案

## 检测环境
- 后端：http://127.0.0.1:8080
- 前端：http://localhost:5173
- 浏览器：Chrome/Edge

---

## 一、笔记 CRUD

### 1.1 创建笔记
| 步骤 | 预期结果 |
|------|---------|
| 点击侧边栏「+」按钮 | 弹出创建笔记对话框 |
| 输入标题「测试笔记」 | 标题输入框显示 |
| 选择文件夹「default」 | 文件夹下拉框显示 |
| 点击「创建」 | 笔记出现在列表中 |

### 1.2 编辑笔记
| 步骤 | 预期结果 |
|------|---------|
| 点击笔记列表中的笔记 | 编辑器打开，显示内容 |
| 修改标题 | 标题输入框更新 |
| 修改内容 | 编辑器内容更新 |
| 等待 800ms | 自动保存（无提示） |

### 1.3 删除笔记
| 步骤 | 预期结果 |
|------|---------|
| 右键笔记 → 删除 | 弹出确认对话框 |
| 点击「确认」 | 笔记从列表消失 |
| 展开回收站 | 笔记出现在回收站 |

### 1.4 恢复笔记
| 步骤 | 预期结果 |
|------|---------|
| 展开回收站 | 显示已删除笔记 |
| 点击「恢复」按钮 | 笔记从回收站消失 |
| 检查笔记列表 | 笔记重新出现 |
