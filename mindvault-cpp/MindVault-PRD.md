## 一、产品愿景

打造一款**本地优先、隐私安全、AI增强**的个人知识管理工具，解决用户「知识收集→整理→链接→检索→复用→创造」的全流程需求。

**核心差异化**:
- ✅ 100%本地存储，无数据绑架
- ✅ 标准Markdown格式，开放可迁移
- ✅ 离线可用，隐私优先
- ✅ 知识图谱可视化（双向链接）

---

## 二、技术架构（已实现）

### 2.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | C++17 + Crow + SQLite3 (FTS5) | REST API服务 |
| 前端 | Vue 3 + TypeScript + Vite | Web前端 |
| 编辑器 | CodeMirror 6 | Markdown编辑 |
| 通信 | HTTP REST API | JSON格式 |

### 2.2 架构图

```
Vue3前端 (Vite开发服务器)
    ↓ HTTP请求 (JSON)
C++后端 (Crow HTTP服务器 :8080)
    ↓ SQLite C API
SQLite数据库 (data/mindvault.db)
```

## 三、功能需求详述

### 3.1 已完成功能（Phase 1）

#### ✅ US-001: 本地存储架构

**用户故事**: 作为用户，我需要创建和管理本地知识库，所有数据100%存储在本地磁盘

**已实现**:
- [x] SQLite数据库存储元数据
- [x] 笔记以数据库记录形式存储（title, content, folder）
- [x] 支持文件夹分类管理
- [x] FTS5全文索引

**技术实现**: SQLite3 + FTS5虚拟表 + 触发器同步

---

#### ✅ US-002: Markdown编辑器

**用户故事**: 作为用户，我需要编辑Markdown笔记，支持实时预览

**已实现**:
- [x] CodeMirror 6编辑器 + oneDark主题
- [x] Markdown工具栏（粗斜体/标题/列表/引用/代码/链接/表格）
- [x] 三种模式切换：编辑 / 分栏 / 预览
- [x] 自动保存（800ms防抖）
- [x] HTML→Markdown自动转换（剪贴板粘贴）
- [x] PDF导出（浏览器打印）
- [x] 快捷键支持（Ctrl+B/I/K/Shift+S）

**技术实现**: CodeMirror 6 + marked + turndown

---

#### ✅ US-003: 文件与内容管理

**用户故事**: 作为用户，我需要管理笔记文件，支持文件夹、标签

**已实现**:
- [x] 左侧文件夹树形结构（FolderTree.vue递归组件）
- [x] 笔记列表（按修改时间排序）
- [x] 右键菜单（重命名/移动/删除/新建）
- [x] 标签体系，单篇笔记可打多个标签
- [x] 回收站（软删除，支持恢复/永久删除/清空）

**技术实现**: NoteService + TagService + 前端状态管理

---

#### ✅ US-004: 离线全文检索

**用户故事**: 作为用户，我需要快速搜索笔记内容

**已实现**:
- [x] 基于SQLite FTS5实现全文检索
- [x] 搜索结果关键词高亮显示（>>>text<<< → <mark>text</mark>）
- [x] 显示匹配上下文预览（snippet函数）
- [x] 增量索引机制（触发器自动同步）
- [x] Ctrl+K全局搜索弹框

**技术实现**: FTS5 MATCH + snippet + 触发器

---

#### ✅ US-005: 双向链接

**用户故事**: 作为用户，我可以通过[[笔记标题]]语法链接其他笔记

**已实现**:
- [x] 支持`[[笔记标题]]`双链语法解析
- [x] 点击双链跳转到目标笔记（不存在则自动创建）
- [x] 编辑器内双链显示为可点击链接样式（紫色标记）
- [x] 右侧面板显示当前笔记的反向/正向链接列表
- [x] 链接关系存储在link_edges表（有向图）

**技术实现**: marked扩展 + link_edges表 + NoteService::UpdateLinks()

## 四、非功能需求

### 4.1 性能要求

| 指标 | 目标值 | 当前状态 |
|-----|-------|---------|
| 应用启动时间 | < 2秒 | ✅ 达标 |
| 1000笔记检索响应 | < 100ms | ✅ FTS5毫秒级 |
| 编辑器输入延迟 | < 16ms | ✅ CodeMirror 6 |

### 4.2 安全要求

- [x] 所有数据100%本地存储
- [x] 参数化查询防SQL注入
